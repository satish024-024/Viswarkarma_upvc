# Competitor Reference: Eternia Design System & Tokens

This document compiles the extracted design system, styling tokens, typography, component parameters, and color palettes from **Eternia Windows** for our platform styling benchmarking.

---

## 🎨 1. Color Palette

| Token | Hex Value | Sample / Purpose |
| :--- | :--- | :--- |

---

## ✍️ 2. Typography & Hierarchy

### Font Families
* **Headings (H1 - H6):** `Archivo` (geometric, clean, professional)
* **Body & Paragraphs:** `Source Sans Pro` (highly legible sans-serif)

### Font Scale Guidelines
* **H1 / Hero Headers:** `72px`
* **H2 / Section Headers:** `37px`
* **Body / Paragraphs:** `28px` (large, highly spaced for accessibility)

---

## 📐 3. Grid & Spacing System
* **Base Spacing Unit:** `4px` (multiples like 8px, 16px, 24px, 32px, 64px for layouts)
* **Default Card/Box Border Radius:** `6px`

## 🔘 4. UI Component styling

### Primary CTA Button
* **Background Color:** `#14B1E7`

* **Border Radius:** `30px` (pill-shaped)
